# Hardware Design Lab Projects

A collection of digital hardware design and simulation projects completed as part of the **Hardware Design Lab** under the guidance of **Professor SB**.

The repository contains both **simulation files** and **breadboard implementation videos** demonstrating the design, testing, and practical realization of several digital systems.

## 📌 Projects

### 1. 0–99 Counter

A digital counter capable of counting from **0 to 99**.

**Included files:**

* `0to99Counter.sim1` — Simulation file
* `0to99CounterVideo.mp4` — Simulation demonstration
* `BreadBoardVideo0to99Counter.mp4` — Breadboard implementation

**Concepts demonstrated:**

* Digital counters
* Sequential logic
* Clock signals
* Multi-digit counting
* Seven-segment/display interfacing

---

### 2. 3-Way Traffic Signal

**Included files:**

* `3wayTrafficSignal.sim1` — Simulation file
* `3_way_traffic_signalVideo.mp4` — Simulation demonstration

**Concepts demonstrated:**

* State-based control
* Timing and sequencing
* Digital control systems

**Concepts demonstrated:**

## 🎯 Learning Outcomes

Through these laboratory projects, I gained practical experience in:

* Designing digital circuits from functional requirements.
* Understanding and implementing **combinational and sequential logic**.
* Designing counters and timing-based digital systems.
* Building and testing a basic **4-bit ALU and control logic**.
* Translating simulated circuits into **physical breadboard implementations**.
* Debugging digital circuits by comparing expected and actual outputs.
* Understanding the relationship between theoretical digital logic and practical hardware implementation.
